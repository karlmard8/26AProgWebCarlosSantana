# Frontend Dispositivo

SPA del módulo de dispositivos, construida con Bun y TypeScript.

Se conecta al backend de dispositivos en `http://localhost:3003`.

## Comandos

```bash
bun install
bun run build
bun run dev
```

## Uso

- Abrir `http://localhost:5173`
- Registrar dispositivos con nombre y precio estimado
- Ver la lista de dispositivos
