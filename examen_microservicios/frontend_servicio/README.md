# Frontend Servicio

SPA del módulo de servicios, construida con Bun y TypeScript.
El frontend se conecta al backend de servicios en `http://localhost:3002`.

## Comandos

```bash
bun install
bun run build
bun run dev
```

## Uso

- Abrir `http://localhost:5172`
- Registrar servicios con nombre de técnico y nombre de dispositivo
- Ver historial de servicios
